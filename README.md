# 足迹

按地级市点选，记录去过的中国城市。

在线使用：<https://julian-zhu2006.github.io/china-footprint/>

## 怎么用

点地图上的一块，记为去过；再点一次取消。滚轮缩放，拖拽平移。右侧可以搜索城市、按省定位，也能把一省全部标上或清空。

三沙市在侧栏的南海诸岛小图里点。

记录保存在这台浏览器里，不会上传。换浏览器或清掉站点数据后，记录会消失。侧栏可以导出、导入一份 JSON 备份。

## 地图上有什么

一共 370 处可点：

- 333 个地级行政区：地级市、自治州、地区、盟
- 北京、天津、上海、重庆各算一处
- 香港、澳门、台湾各算一处
- 海南、新疆另有由省区直辖的县和县级市。这些也做成可点，否则岛上和兵团驻地会空出一块，名单里会标「省直辖」

## 本地打开

下载或克隆后，双击 `index.html` 即可。不需要安装依赖，也不需要服务器。

## 数据

边界来自 [阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，仅供个人记录。`build_map.py` 用来把省级边界收成页面里的 `data/map.js`。
